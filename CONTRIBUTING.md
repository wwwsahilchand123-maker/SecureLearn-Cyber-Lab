# Contributing to SecureLearn Cyber Lab

SecureLearn is intended for cybersecurity education and authorized lab work.

## Guidelines

- Keep examples isolated to legal, controlled environments.
- Never include real credentials, personal data, malware samples, or production logs.
- Explain prerequisites and expected results for new labs.
- Add validation steps or tests when changing reusable lab code.

## Pull requests

Include a concise description, setup requirements, testing performed, and any safety considerations. Avoid instructions that encourage testing against systems without authorization.
